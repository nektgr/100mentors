# Microblog Frontend

This is the frontend application for the Microblog project.

## Prerequisites

Before you begin, ensure you have met the following requirements:
- You have installed [Node.js](https://nodejs.org/) (version 14 or later).
- You have a package manager like [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/).

## Installation

1. Clone the repository:
  ```sh
  git clone https://github.com/yourusername/microblog-front.git
  ```
2. Navigate to the project directory:
  ```sh
  cd microblog-front
  ```
3. Install the dependencies:
  ```sh
  npm install
  ```
  or
  ```sh
  yarn install
  ```

## Running the App

1. Start the development server:
  ```sh
  npm start
  ```
  or
  ```sh
  yarn start
  ```
2. Open your browser and navigate to `http://localhost:3000`.
